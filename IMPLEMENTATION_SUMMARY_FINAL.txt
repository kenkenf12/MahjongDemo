Q1: DISCARD PAYMENT MODEL
   Status:     ✅ Implemented
   Rule:       Only discarder pays, not all 3 losers
   File:       DiscardPaymentCalculator in PaymentCalculator.ts
   Tests:      20+ tests in DiscardWin.test.ts
   Example:
     - East wins on South's discard (2 fan)
     - South pays: 2 points
     - West, North: 0 (not included)
     - East receives: 2 points total

Q2: SELF-DRAW PAYMENT
   Status:     ✅ Implemented
   Rule:       Each of 3 other players pays equally
   File:       SelfDrawPaymentCalculator in PaymentCalculator.ts
   Tests:      20+ tests in SelfDrawWin.test.ts
   Example:
     - East wins by self-draw (2 fan)
     - South, West, North each pay: 2 points
     - East receives: 6 points total

Q3: KONG LIABILITY (PAO)
   Status:     ✅ Implemented
   Rule:       Separate FULL_PAYMENT mode for liability
   File:       FullPaymentCalculator in PaymentCalculator.ts
   Tests:      20+ tests in FullPayment.test.ts
   Example:
     - East wins (2 fan)
     - South is liable player
     - South pays: 6 points (for all 3)
     - East receives: 6 points total

Q4: PAYMENT CAP
   Status:     ✅ Implemented
   Rule:       Payments capped at maximum fan amount
   File:       Settlement.ts (applyCap method)
   Tests:      Tested in all 3 mode test suites
   Example:
     - maxFanForCalculation: 5
     - Hand has 8 fan → calculated as 5
     - Payment: 5 points (not 8)

Q5: NO DEALER MULTIPLIERS
   Status:     ✅ Implemented
   Rule:       Simple consistent calculation (no dealer rates)
   File:       All calculators use uniform baseRate
   Tests:      "No Dealer Multiplier" tests in SelfDrawWin
   Example:
     - East wins: 1 point per fan (same as South, West, North)
     - No position-specific multipliers

🚀 HOW TO USE
──────────────────────────────────────────────────────────────────────────────

1. INSTALL & BUILD:
   cd backend
   npm install
   npm run build

2. RUN TESTS:
   npm test
   npm test:coverage

3. IMPORT IN YOUR GAME:
   import { SettlementEngine, PaymentMode } from './src/index'

4. CREATE ENGINE:
   const engine = new SettlementEngine(DEFAULT_PAYMENT_CONFIG)

5. CALCULATE SETTLEMENT:
   const result = engine.calculateSettlement(
     { position: 'East', fanCount: 2, paymentMode: PaymentMode.DISCARD },
     { position: 'South' },  // Discarder
     null,
     ['East', 'South', 'West', 'North']
   )

6. CHECK RESULT:
   if (result.validation.isValid) {
     // Apply payments
     applySettlement(result)
   } else {
     // Handle errors
     console.error(result.validation.errors)
   }

🔗 INTEGRATION WITH GAME
──────────────────────────────────────────────────────────────────────────────

In your game backend (Durable Object):

  class GameRoom {
    private settlementEngine: SettlementEngine;

    constructor() {
      this.settlementEngine = new SettlementEngine(
        DEFAULT_PAYMENT_CONFIG
      );
    }

    async handleWin(winnerId, fanCount, mode, discarder) {
      const result = this.settlementEngine.calculateSettlement(
        { position: winnerId, fanCount, paymentMode: mode },
        discarder ? { position: discarder } : null,
        null,
        ['East', 'South', 'West', 'North']
      );

      if (result.validation.isValid) {
        // Update player scores
        // Broadcast settlement to clients
        this.applySettlement(result);
      }
    }
  }
